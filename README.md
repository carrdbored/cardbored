# cardbored

### A barebones notes app. 

# Installation

### Windows

Clone the repo:
```bash
  git clone https://github.com/snowballero/cardbored
```

Change directory to the repo
```bash
  cd cardbored
```

Execute the file:
```bash
  python cardbored.py
```

### Linux / macOS

Clone the repo:
```bash
  git clone https://github.com/snowballero/cardbored
```

Change directory to the repo:
```bash
  cd cardbored
```

Execute the file:
```bash
  python3 cardbored.py
```

### Or an all in one

### Windows
```bash
  git clone https://github.com/snowballero/cardbored; cd cardbored; python cardbored.py
```

### Linux / macOS
```bash
  git clone https://github.com/snowballero/cardbored; cd cardbored; python3 cardbored.py
```
